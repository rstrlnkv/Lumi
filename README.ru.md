# Lumi

Браузер для Android в стиле Material 3: адресная строка внизу, жесты, группы вкладок и приватные вкладки, на движке GeckoView.

## Установка

Скачайте `Lumi-<версия>.apk` со страницы [выпусков](https://github.com/rstrlnkv/lumi/releases) и
откройте его на телефоне; Android один раз попросит разрешить установку из приложения, которым вы
его открыли. В каждом выпуске под **Assets** указан SHA-256 файла, так что загрузку можно сначала
проверить:

```bash
shasum -a 256 Lumi-0.1.0-dev.1.apk
```

Чтобы поставить с компьютера, подключите телефон с включённой отладкой по USB и выполните:

```bash
adb install Lumi-0.1.0-dev.1.apk
```

В магазине приложений Lumi пока нет. Сборки с `-dev.N` — предварительные выпуски для ежедневной
проверки.

## Возможности

| Возможность | Что делает |
| --- | --- |
| Адресная строка внизу | Поле адреса стоит внизу, в двух стилях — компактном и классическом. Строка уезжает при прокрутке вниз и возвращается при прокрутке вверх или по нажатию. |
| Жесты на строке | Свайп по строке влево или вправо переключает на соседнюю вкладку; свайп вверх открывает сетку вкладок. |
| Сетка вкладок | Вкладки — крупные карточки. Смахните карточку, чтобы закрыть вкладку. Вкладки возвращаются после перезапуска. |
| Группы вкладок | Вкладки собираются в именованные группы, которые показаны чипами в сетке; свайпы по строке не выходят за текущую группу. |
| Меню по долгому нажатию | На ссылке или картинке: открыть, открыть в новой или фоновой вкладке, скопировать, поделиться, сохранить картинку. |
| Блокировка трекеров | Строгая защита от отслеживания (Enhanced Tracking Protection), щит со счётчиком заблокированных трекеров и переключатель для каждого сайта. |
| Приватные вкладки | Не оставляют истории, закрываются блокировкой экрана телефона и показывают пустую карточку в недавних приложениях. |
| Библиотека | История, закладки с папками и список загрузок. |
| Стартовая страница | Каждая новая вкладка открывает сетку избранных сайтов с их настоящими значками. |
| Поиск | Google, DuckDuckGo, Яндекс, Bing, Startpage или Ecosia, с подсказками при вводе и дополнением адреса, который вы начали набирать. |
| Загрузки | Окно подтверждения, уведомления о ходе загрузки, файлы сохраняются в системную папку «Загрузки». |
| Браузер по умолчанию | Ссылки и поиск из других приложений открываются в Lumi, а «Назад» возвращает в приложение, откуда вы пришли. |
| Цвета сайта | Строка состояния и место под адресной строкой берут цвета страницы; значки на них остаются читаемыми. |
| Обновление жестом | Потяните страницу вниз, чтобы перезагрузить её. |
| Обновления | Раз в сутки Lumi проверяет GitHub Releases этого проекта на сборку новее в выбранном канале — «Стабильные», «Бета» или DEV — и присылает уведомление; оно открывает релиз. |

Интерфейс на английском и русском и следует языку телефона, светлой или тёмной теме и цветам обоев
(Dynamic Color).

## Требования

- Android 8.0 (API 26) или новее, на телефоне с 64-битным процессором ARM (`arm64-v8a`). Других
  архитектур в APK выпуска нет.
- Разрешения, из `app/src/main/AndroidManifest.xml`: `INTERNET`; `POST_NOTIFICATIONS`, запрашивается
  при начале загрузки, для уведомлений о её ходе; `FOREGROUND_SERVICE` и
  `FOREGROUND_SERVICE_DATA_SYNC`, чтобы загрузка шла, когда Lumi в фоне; `WRITE_EXTERNAL_STORAGE`
  только на Android 9 и старше, чтобы сохранить загрузку; `RECEIVE_BOOT_COMPLETED`, чтобы ежедневная
  проверка обновлений пережила перезагрузку; `REQUEST_INSTALL_PACKAGES`, чтобы скачанный APK Lumi можно
  было передать системному установщику. `POST_NOTIFICATIONS` показывает и уведомление об обновлении.
- Сетевые адреса, к которым обращается сам Lumi, кроме открытых вами страниц:
  - выбранная поисковая система — для поиска, а пока включены «Подсказки поисковой системы», ещё и
    для подсказок: `www.google.com` и `suggestqueries.google.com`, `duckduckgo.com`, `yandex.ru` и
    `suggest.yandex.ru`, `www.bing.com` и `api.bing.com`, `www.startpage.com`, `www.ecosia.org` и
    `ac.ecosia.org`;
  - корень `https`, ссылки на значки и `/favicon.ico` каждого сайта со стартовой страницы — за его
    значком;
  - `api.github.com` — раз в сутки и по кнопке «Проверить сейчас», пока включено «Проверять
    обновления», за списком релизов Lumi (без аккаунта и cookie).
  Движок GeckoView со своими настройками по умолчанию, которые Lumi не меняет, ещё загружает списки
  защиты от отслеживания и обновления Safe Browsing с сервисов Mozilla и Google.
- Изменения вне собственных папок Lumi: скачанные файлы попадают в системную папку «Загрузки», а
  браузером по умолчанию Lumi становится, только когда вы подтвердите системный запрос. Данные Lumi
  исключены из облачной резервной копии и из переноса на новое устройство.

## Сборка из исходников

Нужны JDK 21, Android SDK (файл `local.properties` с `sdk.dir=<путь>`, он в `.gitignore`) и
Node.js в `PATH` (модульные тесты запускают под ним скрипт конца страницы). Gradle приходит с
обёрткой.

```bash
./gradlew test lint        # always together: lint catches missing Russian strings
./gradlew assembleDebug    # APK in app/build/outputs/apk/debug/
./gradlew installDebug     # with a phone or an emulator connected (adb devices)
./gradlew assembleRelease  # arm64 only; unsigned unless the LUMI_RELEASE_* Gradle properties are set
```

Название версии — `lumi.version` в `gradle.properties`; номер сборки — число коммитов, поэтому
собирайте из полного клона, не из неглубокого. Как устроен код, описывает
[`ARCHITECTURE.md`](ARCHITECTURE.md) (на английском).
